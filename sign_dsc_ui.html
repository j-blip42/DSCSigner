Which tokens are known to work

This has been used against real tokens from two vendors — two DSCs on ePass2003 / HYP2003 hardware, and an mToken CryptoID (Longmai). The other drivers it looks for are listed on reasonable grounds but have not been proven here.

Yours may well work anyway — any PKCS#11 driver in System32 is found automatically. If it does not, the source is published under the AGPL: add your driver to KNOWN_MODULES in sign_dsc.py and it will be picked up. If that is not your line of work, hand that file to any capable AI assistant and ask it to add your vendor — it is a short list to extend.

3 · Where the signature goes

Pages: 1 · 1,3 · 2-5 · all · first · last — or a mixture, 1,4-6,last. Every page you name gets its own stamp and its own signature, all inside the one signed PDF. A page a document does not have is reported, not signed.

The stamp is placed exactly where you ask for it — nothing is shifted aside to avoid what is already on the page. It is drawn on top, so where it lands on text, a table or an image it will hide it. Preview first: every overlap is named below and again before you sign.

Drag any box to put the signature where you want it — the red box turns green where it is clear of everything on the page. Arrow keys nudge it a point at a time, Shift + arrow ten. What you leave on screen is what gets signed.

Add text puts a remark, a reference number or a date on the page: type it in the box under the page, then drag it into place. Enlarge a page to line it up against a column. The text is written into the page before it is signed, so the signature covers it and it cannot be changed afterwards. Add stamp, Add address and Add letterhead do the same with your saved images; drag them, and set their size under the page.

4 · Sign

The PIN is asked for in a desktop dialog, never in this page — a password box in a browser is something the browser offers to save and sync, and a token PIN must not go anywhere near that. Watch for the prompt; if you cannot see it, check behind this window. Repeated wrong PINs can lock the token.
